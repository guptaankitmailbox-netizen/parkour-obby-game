# Parkour Obby Game

A Python parkour/obby game inspired by Roblox, built while learning to code.

## What this is
A 2D platformer where the player jumps across platforms and obstacles of increasing difficulty, similar to Roblox "obby" (obstacle course) games.

## Built with
- Python
- Pygame

## How to run
1. Install Pygame: `pip install pygame`
2. Run the game: `python main.py`

## Controls
- **Left/Right arrows** — move
- **Space** — jump
